Системи нерівностей: Основи

Означення:

Системою нерівностей називають кілька нерівностей, для яких потрібно знайти всі спільні розв'язки.

  • Розв'язком системи є значення змінної, яке перетворює кожну нерівність системи на правильну числову нерівність.
  • Розв'язати систему — означає знайти множину всіх її розв'язків (переріз множин) або довести, що їх немає.
Алгоритм розв'язання системи:
  1. Розв'язати кожну нерівність системи окремо (як самостійну задачу).
  2. Зобразити множину розв'язків кожної нерівності на одній числовій прямій. Зручно штрихувати їх по різні боки (одна зверху осі, інша — знизу).
  3. Знайти ділянку, де розв'язки всіх нерівностей накладаються один на одного (переріз).
  4. Записати результат у вигляді числового проміжку.
Не плутайте Систему та Сукупність!
  • Система $\begin{cases} \dots \end{cases}$ — це логічне «І». Ми шукаємо виключно переріз (спільну зону накладання).
  • Сукупність $\left[ \begin{array}{l} \dots \\ \dots \end{array} \right.$ — це логічне «АБО». Ми беремо об'єднання всіх заштрихованих проміжків.

Правило «Більше більшого, менше меншого»

Якщо обидві нерівності системи мають \textbf{однакові знаки}, результат можна визначити без малювання осі:

  • Для знаків «$>$»: обираємо найбільше число.
    Наприклад: $\begin{cases} x > 2 \\ x > 7 \end{cases} \implies \mathbf{x > 7}$.
  • Для знаків «$<$»: обираємо найменше число.
    Наприклад: $\begin{cases} x < -1 \\ x < 5 \end{cases} \implies \mathbf{x < -1}$.
