Розділ 1

1. Означення та елементи

Рівнобедрений трикутник -- це трикутник, у якого дві сторони рівні між собою.

  • Бічні сторони -- дві рівні сторони трикутника.
  • Основа -- третя сторона трикутника (та, що відрізняється від бічних).
Розділ 1.2

Властивості висоти, медіани та бісектриси

Головні властивості рівнобедреного трикутника:
  1. Кути при основі рівні між собою ($\angle A = \angle B$).
  2. Супер-властивість: Висота, проведена до основи, є одночасно медіаною та бісектрисою.
  3. Центри вписаного та описаного кіл завжди лежать на цій висоті.

Секрет для НМТ

Лайфхак: Кут $60^\circ$ і Рівносторонній трикутник

🚀 Головний лайфхак рівнобедреного трикутника:

Якщо в задачі сказано, що хоча б один із кутів рівнобедреного трикутника дорівнює $60^\circ$, то цей трикутник автоматично стає рівностороннім (усі його кути $60^\circ$, і всі три сторони рівні).

🧭 Досліди зміну кута при вершині:

Змінюй кут при вершині $C$. Зверни увагу, що стається, коли він досягає $60^\circ$.

Кут при вершині: ∠C = 40°
Кути при основі: (180° - 40°) / 2 = 70°
Тип: Рівнобедрений
Розділ 2 (Практика)

Розв'язання задач: Знаходження кутів

Задача з конспекту:

Кут при вершині рівнобедреного трикутника дорівнює $40^\circ$. Знайдіть кути при основі.

Розв'язання:

  1. Сума кутів трикутника дорівнює $180^\circ$.
  2. Нехай кут при основі дорівнює $x$. Оскільки кути при основі рівні, маємо рівняння: $40^\circ + 2x = 180^\circ$.
  3. $2x = 180^\circ - 40^\circ = 140^\circ \implies x = 70^\circ$.

Відповідь: $70^\circ, 70^\circ$.

🧮 Універсальний калькулятор кутів:

Обери, який кут відомий, введи значення і калькулятор знайде інші.

°
Крок 1: Відомий кут при вершині = 40°.
Крок 2: Кути при основі рівні. (180° - 40°) / 2 = 140° / 2 = 70°.
Відповідь: Кути при основі дорівнюють 70° і 70°.
