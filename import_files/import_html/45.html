Основи

Координати на площині та у просторі

Означення:

Прямокутна система координат (Декартова) -- це спосіб задання положення точки за допомогою чисел (координат). Утворена взаємно перпендикулярними осями, що перетинаються в початку $O(0; 0; 0)$.

Назви осей:
  • $Ox$ -- вісь абсцис;
  • $Oy$ -- вісь ординат;
  • $Oz$ -- вісь аплікат.

Формули

Відстані та поділ відрізків

Відстань між точками $A$ і $B$:

$$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}$$

Середина відрізка $C(x_c; y_c; z_c)$:

$$x_c = \frac{x_1 + x_2}{2}, \quad y_c = \frac{y_1 + y_2}{2}$$

Увага: При обчисленні координат середини використовується ДОДАВАННЯ (середнє арифметичне). Не плутайте з обчисленням координат вектора (де використовується віднімання)!

Секрети НМТ

Специфічні відстані (Лайфхаки)

Відстань від точки $P(x; y; z)$ до:
• початку координат: $d = \sqrt{x^2 + y^2 + z^2}$
• координатної площини (напр. $xy$): $d = |z|$ (модуль відсутньої координати)
• координатної осі (напр. $Oz$): $d = \sqrt{x^2 + y^2}$ (відстань без урахування осі)

Рівняння ліній та поверхонь

Рівняння кола (2D):

$$(x - a)^2 + (y - b)^2 = R^2$$

Рівняння сфери (3D):

$$(x - a)^2 + (y - b)^2 + (z - c)^2 = R^2$$

Типова пастка: Уважно зі знаками! У формулі стоїть мінус. Якщо центр має координату $-3$, то в дужках буде $(x + 3)^2$.
