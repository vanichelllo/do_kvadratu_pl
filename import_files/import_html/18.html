1. Розуміння структури розв'язку

Оскільки тригонометричні функції циклічні, рівняння типу $\sin x = a$ або $\cos x = a$ описують точки на одиничному колі.

  • Формули дають змогу записати всі кути, що потрапляють у ці точки, за допомогою параметра $k \in \mathbb{Z}$.
  • Кожне нове значення $k$ ($0, 1, 2, -1 \dots$) — це новий повний оберт або крок до наступної точки.
Тренажер: $\sin x = a$ та $\cos x = a$
Синус (Y): $\sin x = a$
Горизонтальна лінія. Точки симетричні відносно осі Oy.
Косинус (X): $\cos x = a$
Вертикальна лінія. Точки симетричні відносно осі Ox.

2. Що таке аркфункції?

Обернені тригонометричні функції:

Аркфункції — це математичний інструмент для знаходження кута за відомим значенням тригонометричної функції. Приставка «arc-» перекладається як «дуга» або «кут».

  • $\arcsin a$ — це кут (від $-\frac{\pi}{2}$ до $\frac{\pi}{2}$), синус якого дорівнює $a$.
  • $\arccos a$ — це кут (від $0$ до $\pi$), косинус якого дорівнює $a$.
  • $\operatorname{arctg} a$ — це кут (від $-\frac{\pi}{2}$ до $\frac{\pi}{2}$), тангенс якого дорівнює $a$.
Як швидко знайти значення?

Щоб обчислити, наприклад, $\arcsin\left(\frac{1}{2}\right)$, просто поставте собі запитання:
«Синус якого кута дорівнює $\frac{1}{2}$?»
Згадавши таблицю значень (яка є в довіднику НМТ), ви знайдете відповідь: це кут $30^\circ$, або $\frac{\pi}{6}$ радіан.
Отже, $\arcsin\left(\frac{1}{2}\right) = \frac{\pi}{6}$.

3. Загальні формули та їх властивості

Найпростіші тригонометричні рівняння ❌ Немає в НМТ

Увага! Цих формул немає у довідкових матеріалах тесту. Їх потрібно знати напам'ять.

  • Синус: $\sin x = a \implies x = (-1)^k \arcsin a + \pi k$
  • Косинус: $\cos x = a \implies x = \pm \arccos a + 2\pi k$
  • Тангенс: $\operatorname{tg} x = a \implies x = \operatorname{arctg} a + \pi k$
Властивості обернених функцій ❌ Немає в НМТ

Якщо під знаком аркфункції стоїть від'ємне число, обов'язково застосуйте ці правила перед обчисленням за таблицею:

Віднімаємо від $\pi$:
$\arccos(-a) = \pi - \arccos a$
$\operatorname{arcctg}(-a) = \pi - \operatorname{arcctg} a$
Мінус виноситься наперед:
$\arcsin(-a) = -\arcsin a$
$\operatorname{arctg}(-a) = -\operatorname{arctg} a$
Важливо

4. Окремі випадки ($a = -1, 0, 1$)

Для цих значень загальні формули з попереднього слайда використовувати не можна (це призведе до втрати коренів або помилок)! Відповіді зчитуються безпосередньо з одиничного кола і записуються як одна серія точок.

Значення $a$ Синус ($\sin x = a$) Косинус ($\cos x = a$)
$\mathbf{a = 0}$ $x = \pi k$ $x = \frac{\pi}{2} + \pi k$
$\mathbf{a = 1}$ $x = \frac{\pi}{2} + 2\pi k$ $x = 2\pi k$
$\mathbf{a = -1}$ $x = -\frac{\pi}{2} + 2\pi k$ $x = \pi + 2\pi k$
* Для всіх наведених формул $k \in \mathbb{Z}$.

6. Перетин на графіках функцій

Розв'язки рівняння $\sin x = a$ — це абсциси точок перетину графіка функції $y = \sin x$ та горизонтальної прямої $y = a$.

Порада для НМТ: Якщо в тесті просять знайти «кількість коренів на проміжку», найшвидший спосіб — намалювати графік (хвилю) або одиничне коло і просто порахувати точки перетину в заданих межах, замість того, щоб розв'язувати нерівності з $k$.
