Степінь та його властивості

Розділ 1

1. Базові поняття: Що таке степінь?

Означення степеня

Степенем числа $a$ з натуральним показником $n > 1$ називають добуток $n$ множників, кожен із яких дорівнює $a$:

$$a^n = \underbrace{a \cdot a \cdot \dots \cdot a}_{n \text{ разів}}$$

Де $a$ -- основа (число, яке множимо), $n$ -- показник (кількість множників).

🔍 Живий візуалізатор степеня як добутку:
3⁴ = 3 · 3 · 3 · 3 = 81 (множимо 3 саме на себе 4 рази).
Візуалізація

Анатомія степеня $a^n$

Елементи виразу:
  • Основа ($a$): показує, яке саме число повторюється як множник.
  • Показник ($n$): маленьке число зверху справа, показує скільки разів ми беремо основу.
Розділ 1 (Продовження)

Особливі випадки: степені $0$ та $1$

Нульовий степінь

$$a^0 = 1$$

Для будь-якого $a \neq 0$. Будь-яке ненульове число в степені 0 дорівнює 1!

Перший степінь

$$a^1 = a$$

Число саме по собі береться 1 раз і не змінюється.

Невизначеність

$$0^0$$

Вираз не має змісту (математична невизначеність).

Приклад з конспекту:

$$a^0 = 1 \implies \mathbf{2026^0 = 1}, \quad (-17,5)^0 = 1, \quad \left(\frac{3}{4}\right)^0 = 1$$

Розділ 2 / Властивості 1–3

2. Властивості степенів з однаковими основами

Для $a > 0$ та довільних $m, n \in \mathbb{R}$: 📋 Є в довідкових матеріалах НМТ
  • 1. Множення: при множенні степенів з однаковими основами показники додаються: $$a^m \cdot a^n = a^{m+n}$$
  • 2. Ділення: при діленні степенів з однаковими основами показники віднімаються: $$a^m : a^n = a^{m-n}$$
  • 3. Піднесення степеня до степеня: показники перемножуються: $$(a^m)^n = a^{m \cdot n}$$
🧮 Тренажер операцій з однаковими основами:
3⁸ · 3⁶ = 3¹⁴  |  3⁸ : 3⁶ = 3² = 9  |  (3⁸)⁶ = 3⁴⁸
Розділ 2 / Властивості 4–5

Степінь добутку та Степінь дробу

4. Степінь добутку 📋 Довідник НМТ

$$(ab)^n = a^n b^n$$

Показник застосовується до кожного множника в дужках.

Приклад: $(2y)^4 = 2^4 \cdot y^4 = \mathbf{16y^4}$
5. Степінь дробу 📋 Довідник НМТ

$$\left(\frac{a}{b}\right)^n = \frac{a^n}{b^n}$$

Підносимо окремо і чисельник, і знаменник.

Приклад: $\left(\frac{2}{3}\right)^3 = \frac{2^3}{3^3} = \mathbf{\frac{8}{27}}$
Розділ 2 / Властивість 6

Степінь із від'ємним показником

6. Від'ємний показник 📋 Довідник НМТ

$$a^{-n} = \frac{1}{a^n}$$

Мінус у показнику «перевертає» число (відправляє його в знаменник дробу).

Від'ємний степінь для звичайного дробу:

$$\left(\frac{a}{b}\right)^{-n} = \left(\frac{b}{a}\right)^n$$

Дріб просто перевертається догори дриґом, а мінус у показнику зникає!

Приклад з конспекту:

$$\left(\frac{3}{4}\right)^{-2} = \left(\frac{4}{3}\right)^2 = \frac{4^2}{3^2} = \mathbf{\frac{16}{9}}$$

🔄 Конвертер дробів з від'ємним показником:
(3/4)⁻² = (4/3)² = 16/9 = 1.777...
Розділ 2 / Властивість 7

Степінь із дробовим показником (Зв'язок із коренем)

7. Дробовий показник 📋 Довідник НМТ

$$a^{\frac{m}{n}} = \sqrt[n]{a^m}$$

• Чисельник дробу ($m$) -- це степінь під коренем.
• Знаменник дробу ($n$) -- це степінь кореня.

Типові приклади:
  • $a^{\frac{1}{2}} = \sqrt{a}$
  • $8^{\frac{1}{3}} = \sqrt[3]{8} = \mathbf{2}$
  • $27^{\frac{2}{3}} = \sqrt[3]{27^2} = (\sqrt[3]{27})^2 = 3^2 = \mathbf{9}$
🔄 Конвертер дробового степеня $a^{\frac{m}{n}}$:
27^(2/3) = ³√(27²) = (³√27)² = 3² = 9.
Практичний блок

Покрокові приклади застосування властивостей

Приклад 1: Ділення степенів

$$\frac{a^m}{a^n} = a^{m-n} \implies \frac{3^8}{3^6} = 3^{8-6} = 3^2 = \mathbf{9}$$

Приклад 2: Степінь добутку

$$(ab)^n = a^n b^n \implies (2y)^4 = 2^4 \cdot y^4 = \mathbf{16y^4}$$

Приклад 3: Степінь дробу

$$\left(\frac{a}{b}\right)^n = \frac{a^n}{b^n} \implies \left(\frac{2}{3}\right)^3 = \frac{2^3}{3^3} = \mathbf{\frac{8}{27}}$$

Приклад 4: Від'ємний показник дробу

$$\left(\frac{a}{b}\right)^{-n} = \left(\frac{b}{a}\right)^n \implies \left(\frac{3}{4}\right)^{-2} = \left(\frac{4}{3}\right)^2 = \mathbf{\frac{16}{9}}$$

Увага! Типова помилка

Дужки при від'ємній основі: $(-a)^n$ проти $-a^n$

⚠️ Будьте уважні з дужками при від'ємній основі:
  • $(-3)^2 = (-3) \cdot (-3) = \mathbf{9}$
    Мінус знаходиться всередині дужок, тому парний показник «нищить» мінус!
  • $-3^2 = -(3 \cdot 3) = \mathbf{-9}$
    Мінус стоїть окремо від степеня (підноситься лише число 3, а мінус просто дописується спереду).
⚠️ Інтерактивний детектор мінуса та дужок:
(-3)² = 9 (додатне, бо парний степінь) | -3² = -9 (від'ємне, бо мінус не в степені).
Лайфхак для НМТ

Зведення до найменшої спільної основи

🚀 Головний принцип розв'язання тестів НМТ:

Якщо бачите в завданні різні основи (наприклад, $2, 4, 8$ або $3, 9, 27$) -- завжди зводьте їх до найменшої спільної основи перед тим, як застосовувати властивості!

Сім'я двійки:
$4 = 2^2$
$8 = 2^3$
$16 = 2^4$
$32 = 2^5$
Сім'я трійки:
$9 = 3^2$
$27 = 3^3$
$81 = 3^4$
$243 = 3^5$
Сім'я п'ятірки:
$25 = 5^2$
$125 = 5^3$
$625 = 5^4$
Приклад спрощення: $\frac{8^3 \cdot 4^2}{2^{11}} = \frac{(2^3)^3 \cdot (2^2)^2}{2^{11}} = \frac{2^9 \cdot 2^4}{2^{11}} = \frac{2^{13}}{2^{11}} = 2^2 = \mathbf{4}$.
Підсумок уроку

🎉 Усі властивості степеня засвоєно!

Повний комплект із 7 формул довідника НМТ розібрано та закріплено.

📌 Зведена шпаргалка формул НМТ:
  • $a^m \cdot a^n = a^{m+n}$  |  $a^m : a^n = a^{m-n}$
  • $(a^m)^n = a^{mn}$  |  $(ab)^n = a^n b^n$
  • $(a/b)^n = a^n / b^n$  |  $a^{-n} = 1/a^n$
  • $a^{\frac{m}{n}} = \sqrt[n]{a^m}$  |  $a^0 = 1$
