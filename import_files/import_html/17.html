Основи

1. Означення через одиничне коло

Одиничне коло — це коло з радіусом $R=1$ та центром у початку координат. Кожній точці $P(x; y)$ на колі відповідає певний кут повороту $\alpha$:

  • Косинус ($\cos \alpha$) — це абсциса (координата $x$) точки на колі. ✅ НМТ
  • Синус ($\sin \alpha$) — це ордината (координата $y$) точки на колі. ✅ НМТ
  • Тангенс ($\text{tg } \alpha = \frac{\sin \alpha}{\cos \alpha}$) та Котангенс ($\text{ctg } \alpha = \frac{\cos \alpha}{\sin \alpha}$).
Точка $P(\cos \alpha; \sin \alpha)$
Зверніть увагу: оскільки радіус кола $R=1$, значення синуса та косинуса ніколи не можуть бути більшими за 1 або меншими за -1.
Теорія

2. Основні тотожності та формули

Основні тригонометричні тотожності:
  1. Основна тотожність: $\sin^2 \alpha + \cos^2 \alpha = 1$ ✅ Є в довіднику НМТ
  2. Тангенс та котангенс: $\text{tg } \alpha = \frac{\sin \alpha}{\cos \alpha}, \quad \text{ctg } \alpha = \frac{\cos \alpha}{\sin \alpha}$
  3. Зв'язок функцій: $\text{tg } \alpha \cdot \text{ctg } \alpha = 1$
  4. Наслідки: $1 + \text{tg}^2 \alpha = \frac{1}{\cos^2 \alpha} \quad \text{та} \quad 1 + \text{ctg}^2 \alpha = \frac{1}{\sin^2 \alpha}$
Формули подвійного кута:
  • $\sin 2\alpha = 2\sin \alpha \cos \alpha$ ✅ НМТ
  • $\cos 2\alpha = \cos^2 \alpha - \sin^2 \alpha$ ✅ НМТ

Ці формули є основою для спрощення складних тригонометричних виразів. Майже всі вони доступні в зошиті учасника НМТ, проте їхнє розуміння пришвидшує роботу.

Довідник

3. Формули зведення та значення

Формули зведення використовуються для спрощення виразів. Зверніть увагу на зміну знаку залежно від чверті кола. ✅ Є в довіднику НМТ

Функція $90^\circ + \alpha$ (зміна назви) $180^\circ - \alpha$ (назва лишається)
$\sin$ $\sin(90^\circ + \alpha) = \cos \alpha$ $\sin(180^\circ - \alpha) = \sin \alpha$
$\cos$ $\cos(90^\circ + \alpha) = -\sin \alpha$ $\cos(180^\circ - \alpha) = -\cos \alpha$
$\text{tg}$ $\text{tg}(90^\circ + \alpha) = -\text{ctg } \alpha$ * $\text{tg}(180^\circ - \alpha) = -\text{tg } \alpha$
* У довіднику НМТ котангенс замінено на дріб: $-\frac{1}{\text{tg } \alpha}$

Візуалізація

4. Знаки тригонометричних функцій

Парність: Косинус — єдина парна функція: $\cos(-\alpha) = \cos \alpha$. Усі інші є непарними: $\sin(-\alpha) = -\sin \alpha$, $\text{tg}(-\alpha) = -\text{tg } \alpha$.

Функції

5. Властивості $\sin x$ та $\cos x$

$y = \sin x$
  • $D(y) = (-\infty; +\infty)$
  • $E(y) = [-1; 1]$
  • Період: $T = 2\pi$
  • Непарна
$y = \cos x$
  • $D(y) = (-\infty; +\infty)$
  • $E(y) = [-1; 1]$
  • Період: $T = 2\pi$
  • Парна

Ключове для НМТ: Рівняння $\sin x = a$ або $\cos x = a$ мають розв'язки лише при $|a| \leq 1$. Якщо $a = 2$, розв'язків немає!

Функції

6. Графік та властивості тангенса

$y = \text{tg } x$
  • Область визначення: $x \neq \frac{\pi}{2} + \pi k$ (існують розриви).
  • Область значень: $E(y) = (-\infty; +\infty)$ (на відміну від синуса, тангенс може бути будь-яким числом).
  • Період: $T = \pi$ (графік повторюється частіше).
  • Непарна функція.
