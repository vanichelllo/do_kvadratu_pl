Основи

Лінійні рівняння з однією змінною

Означення:

Лінійним рівнянням називають рівняння вигляду $ax = b$, де $x$ — невідома змінна, $a$ та $b$ — числа (коефіцієнти).

Загальний алгоритм розв'язання:
  1. Спрощення: Розкрити дужки та позбутися дробів.
  2. Групування: З $x$ — вліво, числа — вправо (змінивши знаки).
  3. Зведення: Отримати вигляд $ax = b$.
  4. Результат: Поділити $b$ на $a$.
🔄 Покрокове розв'язання (Інтерактив):
Розв'яжіть рівняння:   $4(x - 3) = 2x + 6$
Дослідження

Кількість коренів рівняння $ax = b$

Скільки існує розв'язків?
  • $a \neq 0$: Один корінь $x = \frac{b}{a}$.
  • $a = 0, b = 0$: $0x = 0$ $\rightarrow$ безліч коренів.
  • $a = 0, b \neq 0$: $0x = b$ $\rightarrow$ коренів немає $\varnothing$.
Секрет НМТ (Параметри):

Якщо в задачі з параметром питають, при якому значенні $a$ рівняння не має коренів, шукайте ситуацію $0 \cdot x = \text{число}$ (наприклад, $0x = 5$).

Модуль

Рівняння з модулем: Геометричний зміст

Що таке модуль? 📋

Модуль (абсолютна величина) — це відстань від точки на числовій прямій до нуля. Відстань не може бути від'ємною!

$|f(x)| = \begin{cases} f(x), & \text{якщо } f(x) \geq 0 \\ -f(x), & \text{якщо } f(x) < 0 \end{cases}$

Практика

Типові схеми розв'язання модулів

Три основні типи:
  • Тип $|f(x)| = a$: Якщо $a \geq 0 \rightarrow$ розпадається на $f(x) = a$ або $f(x) = -a$. (Якщо $a<0 \rightarrow \varnothing$).
  • Тип $|f(x)| = |g(x)|$: Сукупність двох рівнянь: $f(x) = g(x)$ або $f(x) = -g(x)$.
  • Тип $|f(x)| = g(x)$ (змінна справа): Обов'язкова умова (ОДЗ) $g(x) \geq 0$, після чого розкриваємо як сукупність.
Приклад: $|3x - 2| = x + 4$
1. Умова (Справа змінна):
Відстань має бути невід'ємною: $x + 4 \geq 0 \implies \mathbf{x \geq -4}$.
2. Сукупність рівнянь:
$3x - 2 = x + 4$
$2x = 6$
$\mathbf{x = 3}$
АБО
$3x - 2 = -(x + 4)$
$3x - 2 = -x - 4$
$4x = -2 \implies \mathbf{x = -0.5}$
Обидва корені задовольняють умову $x \geq -4$. Відповідь: $\{-0.5; 3\}$.

📌 Золоті правила:
  • Перенесення: Переносимо через дорівнює — змінюємо знак!
  • Параметри: Якщо питають про відсутність коренів, перевіряй умову $0x = b, (b \neq 0)$.
  • Модуль: Це відстань. Вона ніколи не буває від'ємною.
  • Перевірка ОДЗ: Якщо в рівнянні $|f(x)| = g(x)$ справа є ікси, обов'язково пиши $g(x) \geq 0$.
