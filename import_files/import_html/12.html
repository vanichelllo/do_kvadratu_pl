Основи

Квадратична функція: Перше знайомство

Означення:

Квадратичною називають функцію виду $\mathbf{y = ax^2 + bx + c}$, де $x$ — аргумент, $a, b, c$ — параметри ($a \neq 0$). Графіком цієї функції є парабола.

Вплив коефіцієнтів на вигляд графіка:
  • Коефіцієнт $a$: відповідає за напрямок віток. Якщо $a > 0$ — вітки вгору $\cup$, якщо $a < 0$ — вітки вниз $\cap$. Також він визначає "ширину" параболи.
  • Коефіцієнт $c$: ордината точки перетину з віссю $Oy$. Парабола завжди перетинає вісь $y$ у точці $(0; c)$.
  • Дискримінант ($D = b^2 - 4ac$): визначає кількість точок перетину з віссю $Ox$ (нулів функції).
Елементи графіка

Вершина параболи та вісь симетрії

Координати вершини $(x_0; y_0)$:
$x_0 = -\frac{b}{2a}, \quad y_0 = f(x_0)$
  • Пряма $x = x_0$ є віссю симетрії.
  • Якщо $a > 0$, то найменше значення $y_{min} = y_0$.
  • Якщо $a < 0$, то найбільше значення $y_{max} = y_0$.
Лайфхак для знаходження $y_0$:

Якщо підставляти $x_0$ довго через великі числа, використайте дискримінант:

$y_0 = -\frac{D}{4a}$

Дослідіть, як змінюється парабола $\mathbf{y = ax^2 + bx + c}$ при зміні кожного параметра.

$y = x^2$

Теорія

Дискримінант та нулі функції

Дискримінант ($D = b^2 - 4ac$) рівняння $ax^2 + bx + c = 0$ визначає кількість точок перетину параболи з віссю $Ox$ (нулів функції).

Часта помилка! Відсутність перетину з $Ox$ ($D < 0$) не означає, що графіка не існує. Це означає, що вся парабола "висить" над віссю (якщо $a>0$) або лежить повністю під нею (якщо $a<0$).

Методика

Алгоритм визначення знаків $a, b, c, D$

На НМТ часто дають графік і просять визначити знаки коефіцієнтів. Використовуй цей простий 4-кроковий алгоритм:

Крок 1: Знак $a$ (Напрямок віток)

Дивимось на вітки параболи: якщо вгору — $\mathbf{a > 0}$, якщо вниз — $\mathbf{a < 0}$.

Крок 2: Знак $c$ (Перетин з $Oy$)

Дивимось, де графік перетинає вертикальну вісь $y$. Якщо вище початку координат — $\mathbf{c > 0}$, нижче — $\mathbf{c < 0}$, проходить через нуль — $\mathbf{c = 0}$.

Крок 3: Знак $b$ (Положення вершини)

Використовуємо $x_0 = \frac{-b}{2a}$. Лайфхак:
- Якщо вершина справа від $Oy$, то $a$ і $b$ мають різні знаки ($a \cdot b < 0$).
- Якщо вершина зліва від $Oy$, то $a$ і $b$ мають однакові знаки ($a \cdot b > 0$).

Крок 4: Знак $D$ (Перетин з $Ox$)

Рахуємо кількість перетинів з горизонтальною віссю $x$: два перетини $\to \mathbf{D > 0}$, дотикається $\to \mathbf{D = 0}$, не перетинає $\to \mathbf{D < 0}$.

Практика НМТ

Тренажер 1: Знайди знаки

Визначте знаки $a, b, c$ та $D$ за графіком:
$a > 0, b > 0, c > 0, D > 0$
$a < 0, b > 0, c > 0, D > 0$
$a < 0, b < 0, c > 0, D > 0$
$a < 0, b > 0, c < 0, D < 0$
