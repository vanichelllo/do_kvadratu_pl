Розділ 1

1. Основні поняття та сума кутів (Деформація)

Трикутник -- фігура, яка складається з трьох точок (вершин), що не лежать на одній прямій, і трьох відрізків (сторін), які їх сполучають.

Периметр ($P$) -- сума довжин усіх сторін: $P = a + b + c$.

Сума кутів трикутника: 📋 Довідник НМТ

У будь-якому трикутнику сума всіх внутрішніх кутів дорівнює 180°.

$$\alpha + \beta + \gamma = 180^\circ$$

📐 Жива сума кутів:

Рухай вершину C вліво/вправо:

∠A + ∠B + ∠C = 180°
Розділ 2

2. Види трикутників (Жива трансформація)

За сторонами:
  • Різносторонні: усі сторони різні.
  • Рівнобедрені: дві сторони рівні (бічні).
  • Рівносторонні: усі сторони рівні (всі кути по 60°).
За кутами:
  • Гострокутні: усі кути < 90°.
  • Прямокутні: один кут рівно 90°.
  • Тупокутні: один кут > 90°.
🧭 Обертай сторону $AC$, щоб змінити тип трикутника:
∠A = 60°
Тип: Гострокутний
Розділ 3

3. Зовнішній кут трикутника

Зовнішнім кутом називається кут, суміжний із внутрішнім кутом цього трикутника.

Властивості:
  1. Зовнішній кут дорівнює сумі двох внутрішніх, не суміжних із ним:
    $$\beta_{\text{зовн}} = \alpha + \gamma$$
  2. Він більший за будь-який внутрішній кут, не суміжний із ним.
  3. Сума всіх зовнішніх кутів дорівнює 360°.
🔦 Динамічний зовнішній кут:

Змінюй внутрішній кут $\gamma$ (рухай вершину $C$):

β_зовн = α + γ
Розділ 4

4. Лабораторія ліній трикутника

  • Медіана -- до середини сторони. Діляться в точці перетину $2:1$.
  • Бісектриса -- ділить кут навпіл.
  • Висота -- перпендикуляр ($90^\circ$).
  • Середня лінія -- сполучає середини сторін, паралельна основі ($=\frac{1}{2}$ основи).
🧮 Дослідження ліній (особливо в тупокутному трикутнику!):

Рухай вершину $C$, щоб зробити трикутник тупокутним:

Медіана ділить протилежну сторону AB навпіл.
Розділ 5

5. Подібні трикутники ($\sim$)

Подібні трикутники -- це трикутники, у яких відповідні кути рівні, а відповідні сторони пропорційні (однакова форма, різний розмір).

$$\triangle ABC \sim \triangle A_1B_1C_1 \iff \frac{AB}{A_1B_1} = \frac{BC}{B_1C_1} = \frac{AC}{A_1C_1} = k$$

Ознаки подібності:
  1. За двома кутами ($\angle A = \angle A_1, \angle B = \angle B_1$).
  2. За двома сторонами та кутом між ними.
  3. За трьома сторонами (усі сторони пропорційні).
Важливе правило для НМТ:
  • Відношення периметрів дорівнює $k$.
  • Відношення площ дорівнює квадрату коефіцієнта: $\frac{S_1}{S_2} = k^2$.
⚖️ Візуалізатор масштабування (Коефіцієнт $k$):
Коефіцієнт подібності k = 1.5
Сторона: $a_2 = 1.5 \cdot a_1$
Площа: $S_2 = \mathbf{2.25} \cdot S_1$ ($k^2$)
