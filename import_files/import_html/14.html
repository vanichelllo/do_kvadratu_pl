Квадратичні нерівності. Метод параболи

Означення:

Квадратичними називають нерівності виду $ax^2 + bx + c > 0$ (або $<, \leq, \geq$), де $a \neq 0$. Графічним образом лівої частини є парабола.

Алгоритм «Метод параболи»:
  1. Нулі: Розв'язати рівняння $ax^2 + bx + c = 0$ (знайти точки перетину з віссю $Ox$).
  2. Ескіз: Зобразити вітки параболи ($a>0 \implies \cup$, $\; a<0 \implies \cap$). Нас цікавить лише перетин з $Ox$, вісь $Oy$ малювати не потрібно.
  3. Вибір: Позначити проміжки: над віссю (там де $+ $) для знака «$>$», під віссю (там де $-$) для знака «$<$».
Тренажер: $x^2 - 4x + 3 \text{ [ ? ] } 0$
Аналіз

Особливі випадки: Коли $D < 0$

Якщо дискримінант від'ємний ($D < 0$), парабола не перетинає вісь $Ox$. Вона повністю "висить" над віссю ($a>0$) або повністю під нею ($a<0$).

Дослідіть нерівність: $x^2 + x + c > 0$
Методика

Чому працює метод інтервалів?

Уявіть вираз $f(x) = (x-2)(x+3)$. Його нулі: $x=2$ та $x=-3$. Ці точки розбивають вісь на три інтервали. На кожному з них вираз зберігає свій знак. Щоб його дізнатися, достатньо підставити будь-яке число з цього інтервалу!

Теорія

Раціональні нерівності та метод інтервалів

Означення:

Раціональною називають нерівність виду $\frac{P(x)}{Q(x)} > 0$. Головна особливість: ми не можемо просто помножити ліву і праву частину на знаменник, оскільки його знак залежить від $x$. Тому використовується метод інтервалів.

Базовий алгоритм методу інтервалів:
  1. Знайти нулі чисельника (точки, де вираз дорівнює 0).
  2. Знайти нулі знаменника (точки, де вираз не існує — ОДЗ).
  3. Позначити всі ці точки на числовій осі.
  4. Визначити знак виразу на кожному інтервалі підстановкою будь-якого числа. Знаки «$+$» та «$-$» зручно ставити прямо над відповідним проміжком.

Точки, що прийшли зі знаменника, на числовій осі завжди малюються порожніми (виколотими) $\circ$, незалежно від того, строгий ($>$) чи нестрогий ($\geq$) знак стоїть у нерівності.

Головна пастка НМТ!

Якщо лінійний множник (дужка) стоїть у парному степені (наприклад, $(x-3)^2$ або $x^4$), то при переході через цей корінь на числовій осі знак нерівності не змінюється. Квадрат числа завжди "з'їдає" мінус!

Підстановка контрольних точок з кожного проміжку — це найнадійніший спосіб не потрапити в цю пастку. Ви самі побачите, як парний степінь перетворює від'ємне значення дужки на додатне.
