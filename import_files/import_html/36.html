Чотирикутники: Від довільного до квадрата

Означення та базові властивості:
  • Сума внутрішніх кутів: Завжди $\angle A + \angle B + \angle C + \angle D = 360^\circ$.
  • Периметр ($P$): Сума довжин усіх сторін.
  • Нерівність: Будь-яка сторона завжди менша за суму трьох інших.

Лайфхак координатної площини НМТ: Щоб знайти площу нестандартного чотирикутника на клітинках, впишіть його в прямокутник і відніміть площі прямокутних трикутників по краях!

Розділ 2

Паралелограм та його бісектриса

Властивості паралелограма:
  • Протилежні сторони і кути рівні.
  • Сума сусідніх кутів дорівнює $180^\circ$.
  • Діагоналі точкою перетину діляться навпіл.
  • $d_1^2 + d_2^2 = 2(a^2 + b^2)$.
🚀 Головний лайфхак (Бісектриса):

Бісектриса кута паралелограма завжди відтинає рівнобедрений трикутник. Це "класика" завдань НМТ!

📐 Досліди бісектрису (Жива модель):
Змінюйте кут паралелограма та натисніть кнопку, щоб побачити властивість.
Розділи 3-4

Прямокутник та Живий Ромб

Прямокутник
  • Всі кути по $90^\circ$.
  • Діагоналі рівні ($AC = BD$).
  • Діагоналі ділять його на 4 рівновеликих трикутника (пари протилежних -- рівнобедрені).
  • Можна описати коло ($R = d/2$).
Ромб
  • Всі сторони рівні.
  • Діагоналі перпендикулярні ($d_1 \perp d_2$).
  • Діагоналі є бісектрисами кутів.
  • Можна вписати коло ($r = h/2$).

Розділи 5-6

Квадрат та Трапеція

Квадрат:

Ідеальна фігура (Прямокутник + Ромб). Діагональ утворює кути $45^\circ$.

$$d = a\sqrt{2}$$

Трапеція:

Дві сторони паралельні (основи), дві -- ні. Сума кутів при бічній стороні $= 180^\circ$.

Сер. лінія: $m = \frac{a+b}{2}$

📐 Секрет Рівнобічної Трапеції: Дві висоти

Якщо провести дві висоти, вони відітнуть на більшій основі відрізки: з країв по $(a-b)/2$, а посередині $b$.

Розділ 8

Вписані та Описані кола

Описаний чотирикутник

(Коло всередині - вписане)

$$a + c = b + d$$

Суми протилежних сторін рівні. Площа: $S = p \cdot r$. Вписуємо в ромб і квадрат.

Вписаний чотирикутник

(Коло навколо - описане)

$$\angle A + \angle C = 180^\circ$$

Суми протилежних кутів = 180°. Описуємо навколо прямокутника, квадрата і рівнобічної трапеції.

⭕ Перевірка описаного чотирикутника (Вписане коло):
Сторони підряд:
a+c = 5+6 = 11. b+d = 7+4 = 11. Коло вписати МОЖНА!
