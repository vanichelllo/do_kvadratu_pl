Основи

1. Теорія ймовірностей

Класичне означення ймовірності:

Ймовірністю події $A$ називають відношення кількості сприятливих для цієї події наслідків ($m$) до загальної кількості всіх рівноможливих наслідків ($n$).

$P(A) = \frac{m}{n}$ ✅ НМТ
Основні властивості:
  • $0 \le P(A) \le 1$ — ймовірність не може бути від'ємною або $> 1$.
  • $P(U) = 1$ — достовірна подія (точно відбудеться).
  • $P(\emptyset) = 0$ — неможлива подія (ніколи не відбудеться).
  • $P(\bar{A}) = 1 - P(A)$ — ймовірність протилежної події.
Тренажер: Ймовірність витягнути червону кульку
Статистика

2. Елементи математичної статистики

Нехай маємо впорядкований ряд даних: $x_1, x_2, \dots, x_n$.

  • Розмах ($R$): $x_{max} - x_{min}$.
  • Мода ($M_o$): Значення, що зустрічається найчастіше.
  • Медіана ($M_e$): Серединне значення впорядкованого ряду.
    (Якщо $n$ — парне, $M_e$ — середнє арифметичне двох центральних).
  • Середнє значення ($\bar{x}$): $\bar{x} = \frac{x_1 + x_2 + \dots + x_n}{n}$.

Графіки

3. Візуалізація даних

Частотна таблиця — це таблиця, у якій кожному значенню вибірки ($x_i$) відповідає його частота ($n_i$) — кількість разів, яку це значення зустрічається у вибірці.

  • Гістограма — стовпчаста діаграма (висота стовпця = частота).
  • Полігон частот — ламана лінія, що з'єднує точки $(x_i; n_i)$.

НМТ Секрети

4. Поради для НМТ та Кругова діаграма

Швидкий аналіз діаграм:
  • Мода на гістограмі — це найвищий стовпчик.
  • Сума частот ($n_i$) завжди дорівнює загальній кількості елементів вибірки ($n$).
  • Кругова діаграма: кут сектора пропорційний частоті. Формула: $\alpha = \frac{n_i}{n} \cdot 360^\circ$.
