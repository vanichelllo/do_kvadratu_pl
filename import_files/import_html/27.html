Основи

1. Поняття первісної та невизначеного інтеграла

Функція $F(x)$ називається первісною для функції $f(x)$ на проміжку $I$, якщо для кожного $x \in I$ виконується рівність:

$F'(x) = f(x)$

Сукупність усіх первісних для функції $f(x)$ називається невизначеним інтегралом:

$\int f(x) \, dx = F(x) + C, \quad C \in \mathbb{R}$
Візуалізація: Звідки береться $+ C$?

Похідна (швидкість росту) для всіх цих парабол однакова: $f(x) = 2x$.

3. Визначений інтеграл та його властивості

Формула Ньютона-Лейбніца: ✅ НМТ
$\displaystyle \int_{a}^{b} f(x) \, dx = F(x) \Big|_a^b = F(b) - F(a)$
Приклад: Знайдіть інтеграл $\displaystyle \int_{1}^{2} (3x^2 - 1) \, dx$
Геометрія

4. Площа криволінійної трапеції

Криволінійна трапеція — це фігура, обмежена графіком $y = f(x)$, віссю $Ox$ та прямими $x = a$, $x = b$.

Геометричний зміст: Площа дорівнює визначеному інтегралу:

$S = \int_{a}^{b} f(x) \, dx$

Якщо функція $f(x)$ лежить нижче осі $Ox$, то інтеграл буде від'ємним. Площу тоді шукають як: $S = -\int f(x) \, dx$.

Приклад: Площа під $y = x^2 + 1$ від $0$ до $b$
Геометрія

5. Площа фігури, обмеженої двома кривими

Головне правило: Завжди віднімайте «нижню» функцію від «верхньої»!

$S = \int_{a}^{b} \big( f(x)_{верх} - g(x)_{низ} \big) \, dx$
Приклад: Площа між лініями $y=x^2$ та $y=x+2$
