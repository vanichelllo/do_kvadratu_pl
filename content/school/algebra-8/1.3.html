Скільки зроблять двоє за годину? 🛠️

Перший майстер викладає плитку у ванній за $x$ год, другий — за $x + 2$ год. За $1$ год перший виконує $\dfrac{1}{x}$ роботи, другий — $\dfrac{1}{x + 2}$.

Яку частину роботи вони виконають разом за $1$ год?

Треба додати $\dfrac{1}{x} + \dfrac{1}{x + 2}$ — дроби, у знаменниках яких змінні. Як це зробити, щоб відповідь працювала для будь-якого $x$?

Так само, як звичайні дроби

Зводимо до спільного знаменника $x(x + 2)$:

$\dfrac{1}{x} + \dfrac{1}{x + 2} = \dfrac{x + 2 + x}{x(x + 2)} = \dfrac{2x + 2}{x(x + 2)}$

Наприклад, при $x = 4$: $\;\dfrac{10}{24} = \dfrac{5}{12}$ роботи за годину. Сьогодні — правила й пастки таких перетворень.

Основи

Однакові знаменники

Правило

Щоб додати (відняти) раціональні дроби з однаковими знаменниками, додають (віднімають) чисельники, а знаменник залишають тим самим:

$\dfrac{a}{c} + \dfrac{b}{c} = \dfrac{a + b}{c}, \qquad \dfrac{a}{c} - \dfrac{b}{c} = \dfrac{a - b}{c}$

Після дії — спробуйте скоротити

Результат часто скорочується. Але скорочувати можна лише множники, а не доданки.

Приклад. $\dfrac{3x}{x - 2} - \dfrac{6}{x - 2}$

$= \dfrac{3x - 6}{x - 2}$ — знаменники однакові, віднімаємо чисельники.
$= \dfrac{3(x - 2)}{x - 2}$ — винесли спільний множник.
$= 3$ при $x \ne 2$ — скоротили на $x - 2$.
Теорія

Різні знаменники: спільний знаменник

Як і зі звичайними дробами

За основною властивістю дробу $\dfrac{a}{b} = \dfrac{ak}{bk}$ ($k \ne 0$) зводимо дроби до спільного знаменника. Множник $k$ — додатковий множник.

Найпростіший спільний знаменник

Розкладіть знаменники на множники й візьміть кожен множник у найбільшому степені.

$x^2 - 9 = (x - 3)(x + 3)$, тож для $\dfrac{1}{x^2 - 9}$ і $\dfrac{1}{x + 3}$ досить $(x - 3)(x + 3)$.

Дослідження

Перевіряємо відповідь числами 🔍

Обираємо $x$. Учні обчислюють $A = \dfrac{1}{x} + \dfrac{1}{x + 2}$ і $B = \dfrac{2x + 2}{x(x + 2)}$ — потім перевіряємо. При яких $x$ вирази не мають змісту?

Висновок

Значення збігаються — так і має бути: ми робили тотожні перетворення. Але лише при $x \ne 0$ і $x \ne -2$: там знаменник дорівнює нулю.

Алгоритм

Дроби з різними знаменниками крок за кроком

Алгоритм

1) Розкласти знаменники на множники.

2) Знайти найпростіший спільний знаменник.

3) Знайти додаткові множники й домножити чисельники.

4) Додати (відняти) чисельники; мінус перед дробом — у дужки.

5) Спростити чисельник і скоротити дріб, якщо можна.

Спростимо: $\dfrac{2}{x - 3} - \dfrac{12}{x^2 - 9}$.

Приклад

Протилежні знаменники і «зручні» різниці

а) Спростіть $\dfrac{x}{x - y} + \dfrac{y}{y - x}$.

$y - x = -(x - y)$, тож $\dfrac{y}{y - x} = -\dfrac{y}{x - y}$.
$\dfrac{x}{x - y} - \dfrac{y}{x - y} = \dfrac{x - y}{x - y}$.
$= 1$ при $x \ne y$. Спільний знаменник знайшли, просто змінивши знак.

б) Спростіть $\dfrac{1}{a} - \dfrac{1}{a + 1}$.

Спільний знаменник $a(a + 1)$; додаткові множники: $a + 1$ і $a$.
$\dfrac{(a + 1) - a}{a(a + 1)} = \dfrac{1}{a(a + 1)}$.
Наслідок: $\dfrac{1}{2} - \dfrac{1}{3} = \dfrac{1}{6}$, $\;\dfrac{1}{3} - \dfrac{1}{4} = \dfrac{1}{12}$ — так обчислюють суми на кшталт $\dfrac{1}{1 \cdot 2} + \dfrac{1}{2 \cdot 3} + \ldots$
Пастки

Типові помилки ⚠️

Знаменники не додають

$\dfrac{1}{a} + \dfrac{1}{b} \ne \dfrac{2}{a + b}$. Контрприклад $a = b = 1$: $\;2 \ne 1$. Правильно: $\dfrac{a + b}{ab}$.

Мінус перед дробом

$\dfrac{x}{x - 1} - \dfrac{x + 1}{x - 1} = \dfrac{x - (x + 1)}{x - 1} = \dfrac{-1}{x - 1}$, а не $\dfrac{x - x + 1}{x - 1}$.

Скорочують доданки

$\dfrac{x + 3}{x} \ne 3$ і $\dfrac{x + 3}{x} \ne 1 + 3$. Скорочують лише множники: $\dfrac{x + 3}{x} = 1 + \dfrac{3}{x}$.

Забувають про ОДЗ

$\dfrac{3x - 6}{x - 2} = 3$ лише при $x \ne 2$: при $x = 2$ ліва частина не має змісту.

Практика

Практика ✏️

Спростіть $\dfrac{5a}{a + b} + \dfrac{5b}{a + b}$.

А) $5$
Б) $\dfrac{5a + 5b}{2a + 2b}$
В) $\dfrac{10}{a + b}$
Г) $5(a + b)$

Розв'язання

$\dfrac{5a + 5b}{a + b} = \dfrac{5(a + b)}{a + b} = 5$ (при $a + b \ne 0$).

Б — додали знаменники; В — «додали» $a$ і $b$ як числа; Г — помножили замість ділення.

Спростіть $\dfrac{3}{x} - \dfrac{2}{x + 1}$.

А) $\dfrac{1}{x(x + 1)}$
Б) $\dfrac{x + 3}{x(x + 1)}$
В) $\dfrac{x - 3}{x(x + 1)}$
Г) $\dfrac{5x + 3}{x(x + 1)}$

Розв'язання

$\dfrac{3(x + 1) - 2x}{x(x + 1)} = \dfrac{3x + 3 - 2x}{x(x + 1)} = \dfrac{x + 3}{x(x + 1)}$.

А — забули додаткові множники; В — помилка в знаку: $3(x + 1) = 3x + 3$; Г — додали $2x$ замість віднімання.

Спростіть $\dfrac{x}{x - 2} - \dfrac{4}{x^2 - 2x}$.

А) $\dfrac{x + 2}{x}$
Б) $\dfrac{x - 2}{x}$
В) $\dfrac{x - 4}{x - 2}$
Г) $1$
Д) $\dfrac{x^2 - 4}{x - 2}$

Розв'язання

$x^2 - 2x = x(x - 2)$ — спільний знаменник. Додатковий множник першого дробу — $x$.

$\dfrac{x \cdot x - 4}{x(x - 2)} = \dfrac{(x - 2)(x + 2)}{x(x - 2)} = \dfrac{x + 2}{x}$ ($x \ne 0$, $x \ne 2$).

В — забули додатковий множник; Д — загубили множник $x$ у знаменнику.

Коротко

Коротко про тему 📌

Запам'ятай! ⭐

$\dfrac{a}{c} \pm \dfrac{b}{c} = \dfrac{a \pm b}{c}$. Різні знаменники — зводимо до спільного: $\dfrac{a}{b} + \dfrac{c}{d} = \dfrac{ad + bc}{bd}$.

Найпростіший спільний знаменник — після розкладання знаменників на множники.

Алгоритм ✍️

Розклади знаменники → спільний знаменник → додаткові множники → чисельники в дужках → скороти.

Головна пастка ⚠️

Знаменники не додають: $\dfrac{1}{a} + \dfrac{1}{b} \ne \dfrac{2}{a + b}$. Мінус перед дробом змінює знак усього чисельника.
