Що треба знати

Шпаргалка розділу 📋

Ознаки рівності

1) $SAS$: дві сторони і кут між ними. 2) $ASA$: сторона і два прилеглі кути. 3) $SSS$: три сторони.

Прямокутні: два катети; катет і кут; гіпотенуза і кут; гіпотенуза і катет.

Рівнобедрений трикутник

Кути при основі рівні (і навпаки).

Бісектриса до основи = медіана = висота.

Кути трикутника

$\angle A + \angle B + \angle C = 180^\circ$; зовнішній $= $ сума двох не суміжних.

Прямокутний: катет проти $30^\circ$ $= \dfrac12$ гіпотенузи.

Як доводити рівність

1) Виписати рівні елементи (спільна сторона, вертикальні кути!). 2) Вибрати ознаку. 3) Рівні трикутники — рівні відповідні елементи.

Зв'язки

Яке правило тут потрібне? 🔗

Учні визначають, яка ознака чи властивість потрібна, потім відкриваємо відповідь.

Розбір

Рівність + рівнобедрений

Задача

На основі $AC$ рівнобедреного $\triangle ABC$ взято точки $M$ і $K$ так, що $AM = CK$. Доведіть, що $BM = BK$.

Розв'язання
$AB = CB$ (бічні сторони), $\angle A = \angle C$ (кути при основі, 3.3).
$AM = CK$ (умова) ⟹ $\triangle ABM = \triangle CBK$ за першою ознакою (3.2).
Отже, $BM = BK$ як відповідні сторони. ∎
Розбір

Кути + прямокутний

Задача

У $\triangle ABC$ $\angle C = 90^\circ$, зовнішній кут при $B$ дорівнює $120^\circ$, $AB = 18$ см. Знайдіть $BC$.

Розв'язання
$\angle B = 180 - 120 = 60^\circ$ (3.5), тоді $\angle A = 30^\circ$.
$BC$ лежить проти кута $A = 30^\circ$ (3.6).
$BC = 18 : 2 = 9$ см.
Пастки

Типові помилки розділу ⚠️

3.2: у першій ознаці кут має бути між сторонами; дві сторони і кут не між ними — рівності не гарантують.
3.3: бісектриса = медіана = висота — лише для відрізка, проведеного до основи.
3.5: зовнішній кут при $C$ $= \angle A + \angle B$ (без $\angle C$).
3.6: половині гіпотенузи дорівнює катет проти кута $30^\circ$.
Перевір себе

Перевір себе ✏️

1. Кути трикутника відносяться як $1 : 2 : 3$. Знайдіть найбільший.

А) $90^\circ$
Б) $60^\circ$
В) $120^\circ$
Г) $30^\circ$
Д) $180^\circ$

Розв'язання

$6x = 180^\circ$, $x = 30^\circ$, найбільший $90^\circ$.

2. Периметр рівнобедреного трикутника $26$ см, основа $8$ см. Бічна сторона?

А) $9$ см
Б) $18$ см
В) $8$ см
Г) $10$ см
Д) $13$ см

Розв'язання

$(26 - 8) : 2 = 9$ см.

Перевір себе

Ще складніше 🚀

3. У $\triangle ABC$ $\angle A = 40^\circ$, $\angle B = 60^\circ$, $CL$ — бісектриса. Знайдіть $\angle BLC$.

А) $80^\circ$
Б) $100^\circ$
В) $40^\circ$
Г) $60^\circ$
Д) $120^\circ$

Розв'язання

$\angle C = 80^\circ$, $\angle BCL = 40^\circ$; $\angle BLC = 180 - 60 - 40 = 80^\circ$.

4. У прямокутному трикутнику гострий кут $60^\circ$, сума гіпотенузи і меншого катета $24$ см. Знайдіть гіпотенузу.

А) $16$ см
Б) $12$ см
В) $8$ см
Г) $18$ см
Д) $20$ см

Розв'язання

Менший катет проти $30^\circ$: $c + \dfrac{c}{2} = 24$, $c = 16$ см.

Коротко

Коротко про розділ 📌

Головне

Три ознаки рівності (+ чотири для прямокутних). Рівнобедрений: кути при основі рівні, бісектриса = медіана = висота.

Сума кутів $180^\circ$, зовнішній = сума двох не суміжних, катет проти $30^\circ$ — половина гіпотенузи.

Як обрати правило

Довести рівність відрізків чи кутів — знайти рівні трикутники (3.2, 3.4, 3.6). Знайти кут — сума кутів (3.5). Відрізки в рівнобедреному — 3.3, 3.7.

Головна пастка

Не забувайте спільні сторони й вертикальні кути — це найчастіші «приховані» рівні елементи.
