Що треба знати

Шпаргалка розділу 📋

Степені й одночлени

$a^m a^n = a^{m+n}$, $\;(a^m)^n = a^{mn}$, $\;(ab)^n = a^n b^n$.

Стандартний вигляд: $-3a^2b^3$ — коефіцієнт і степені різних змінних.

Дії з многочленами

$a(b + c) = ab + ac$; $\;(a + b)(c + d) = ac + ad + bc + bd$.

Мінус перед дужками змінює знаки всіх членів.

Розклад на множники

Спільний множник: $6x^2 - 9x = 3x(2x - 3)$.

Групування: $ax - ay + 2x - 2y = (x - y)(a + 2)$.

Перевірка

Тотожність перевіряйте підстановкою кількох чисел; розклад — множенням.

Зв'язки

Яке правило тут потрібне? 🔗

Учні визначають, яка тема розділу потрібна, потім відкриваємо відповідь.

Розбір

Спрощення і значення

Задача

Спростіть і знайдіть значення при $x = -2$: $(x + 3)(x - 1) - x(x + 4)$.

Розв'язання
$(x + 3)(x - 1) = x^2 + 2x - 3$ (2.6); $\;x(x + 4) = x^2 + 4x$ (2.5).
Різниця (2.4): $x^2 + 2x - 3 - x^2 - 4x = -2x - 3$.
При $x = -2$: $4 - 3 = 1$.
Розбір

Розклад і рівняння

Задача

Розв'яжіть рівняння $x^3 - 3x^2 - 4x + 12 = 0$.

Розв'язання
Групування (2.8): $x^2(x - 3) - 4(x - 3) = (x - 3)(x^2 - 4)$.
$x - 3 = 0$ або $x^2 = 4$.
Корені: $3$, $2$, $-2$.
Пастки

Типові помилки розділу ⚠️

2.2: $a^2 \cdot a^3 = a^5$, а не $a^6$; $(a^2)^3 = a^6$.
2.4: $-(x - 3) = -x + 3$ — змінюємо знаки всіх членів.
2.6: $(x + 3)(x + 2) \ne x^2 + 6$ — пропущені «перехресні» добутки.
2.7–2.8: $3x^2 + 3x = 3x(x + 1)$ — не губіть $1$; $a(x + y) + 3(x + y)$ — ще не добуток.
Перевір себе

Перевір себе ✏️

1. Спростіть $(-2x^2y)^3$.

А) $-8x^6y^3$
Б) $-6x^6y^3$
В) $8x^6y^3$
Г) $-8x^5y^3$
Д) $-2x^6y^3$

Розв'язання

$(-2)^3 x^{6} y^3 = -8x^6y^3$.

2. Розкладіть $12a^2b - 18ab^2$.

А) $6ab(2a - 3b)$
Б) $6a(2ab - 3b^2)$
В) $3ab(4a - 6b)$
Г) $6ab(2a + 3b)$
Д) $ab(12a - 18b)$

Розв'язання

НСД $6$, $a$, $b$: $6ab(2a - 3b)$. Б, В, Д — не весь множник.

Перевір себе

Ще складніше 🚀

3. Знайдіть значення $a^2b + ab^2$, якщо $a + b = 7$, $ab = -3$.

А) $-21$
Б) $21$
В) $4$
Г) $-10$
Д) $10$

Розв'язання

$ab(a + b) = -21$.

4. Розв'яжіть $(x - 2)(x + 3) - x(x + 4) = 0$.

А) $-2$
Б) $2$
В) $-6$
Г) $6$
Д) $0$

Розв'язання

$x^2 + x - 6 - x^2 - 4x = -3x - 6 = 0$, $x = -2$.

Коротко

Коротко про розділ 📌

Головне

Степені: показники додаються при множенні, множаться при піднесенні до степеня.

Многочлени: розкрити дужки, звести подібні. Розклад: спільний множник, групування.

Як обрати правило

Спростити — розкрити дужки (2.4–2.6); розв'язати рівняння чи скоротити — розкласти на множники (2.7–2.8).

Головна пастка

$(x + 3)(x + 2) \ne x^2 + 6$; $3x^2 + 3x \ne 3x \cdot x$.
