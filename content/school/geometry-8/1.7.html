Навіщо це

Навколо якого чотирикутника можна описати коло?

Навколо будь-якого трикутника можна описати коло. А навколо чотирикутника — не завжди: через три вершини коло пройде, а четверта може «не влучити».

Так само вписати коло (дотичне до всіх сторін) можна не в кожен чотирикутник.

Ключ — кути і сторони

Описати коло можна ⟺ сума протилежних кутів $180^\circ$. Вписати коло можна ⟺ суми протилежних сторін рівні.

Теорія

Чотирикутник, вписаний у коло

Вписаний: усі вершини на колі

$\angle A + \angle C = \angle B + \angle D = 180^\circ$

І навпаки: сума протилежних кутів $180^\circ$ ⟹ можна описати коло.

Чому
$\angle A$ і $\angle C$ — вписані, спираються на дуги $BCD$ і $BAD$.
Дуги разом — $360^\circ$, кути — половини: $\angle A + \angle C = 180^\circ$. ∎
Дослідження

Рухаємо вершину по колу

Вершина $C$ рухається по колу. Учні передбачають, як зміняться $\angle A$, $\angle C$ та їхня сума, — потім вимірюємо.

Теорія

Чотирикутник, описаний навколо кола

Описаний: усі сторони дотикаються до кола

$AB + CD = BC + AD$

І навпаки: суми протилежних сторін опуклого чотирикутника рівні ⟹ можна вписати коло.

Чому
Відрізки дотичних з однієї вершини рівні: позначимо їх $a$, $b$, $c$, $d$.
$AB + CD = (a + b) + (c + d)$, $BC + AD = (b + c) + (d + a)$ — однаково. ∎
Алгоритм

Які чотирикутники?

Описати коло можна

✓ прямокутник, квадрат (кути по $90^\circ$)

✓ рівнобічна трапеція

✗ паралелограм, що не є прямокутником; ромб, що не є квадратом

Центр описаного кола прямокутника — точка перетину діагоналей.

Вписати коло можна

✓ ромб, квадрат (усі сторони рівні)

✓ трапеція, у якої сума основ дорівнює сумі бічних сторін

✗ прямокутник, що не є квадратом

Діаметр вписаного в трапецію кола дорівнює її висоті.

Приклад

Розв'язуємо задачі

Задачі

1) Кути $A$, $B$, $C$ вписаного чотирикутника відносяться як $2 : 3 : 7$. Знайдіть $\angle D$.

2) У рівнобічну трапецію з основами $4$ і $16$ вписано коло. Знайдіть бічну сторону.

Пастки

Типові помилки ⚠️

Не ті кути

$180^\circ$ дають протилежні кути ($A$ і $C$), а не сусідні ($A$ і $B$).

Не ті сторони

Рівні суми протилежних сторін: $AB + CD = BC + AD$.

Переплутали ознаки

Кути — для описаного кола (вершини на колі); сторони — для вписаного (сторони дотикаються).

«Будь-який паралелограм»

Навколо паралелограма можна описати коло, лише якщо він прямокутник; вписати — лише якщо ромб.

Практика

Практика ✏️

$ABCD$ вписаний у коло, $\angle B = 112^\circ$. Знайдіть $\angle D$.

А) $112^\circ$
Б) $68^\circ$
В) $248^\circ$
Г) $56^\circ$

Розв'язання

$180^\circ - 112^\circ = 68^\circ$. В — від $360^\circ$, Г — половина.

$ABCD$ описаний навколо кола, $AB = 7$, $BC = 9$, $CD = 12$. Знайдіть $AD$.

А) $14$
Б) $10$
В) $16$
Г) $4$

Розв'язання

$AB + CD = BC + AD$: $19 = 9 + AD$, $AD = 10$. А — сусідні сторони.

Периметр рівнобічної трапеції, описаної навколо кола, — $40$. Знайдіть бічну сторону.

А) $20$
Б) $10$
В) $5$
Г) $8$
Д) недостатньо даних

Розв'язання

Сума основ = сума бічних = $20$; бічні рівні: по $10$.

Коротко

Коротко про тему 📌

Головне

Вписаний у коло: $\angle A + \angle C = \angle B + \angle D = 180^\circ$ (і навпаки).

Описаний навколо кола: $AB + CD = BC + AD$ (і навпаки).

Пам'ятка

Описати коло: прямокутник, рівнобічна трапеція. Вписати коло: ромб, квадрат.

Пастка

Беремо протилежні кути і протилежні сторони.
