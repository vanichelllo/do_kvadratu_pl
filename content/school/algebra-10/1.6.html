Основи

Ірраціональні рівняння

Означення

Рівняння, у якому змінна міститься під знаком кореня, називають ірраціональним:

$\sqrt{x + 2} = x$, $\quad \sqrt[3]{2x - 1} = 3$, $\quad \sqrt{x} + \sqrt[4]{x} = 6$.

ОДЗ

Корінь парного степеня $\sqrt[2k]{a}$ існує лише при $a \ge 0$, і $\sqrt[2k]{a} \ge 0$. Корінь непарного степеня існує при будь-якому $a$.

ОДЗ рівняння $\sqrt{x + 2} = x$: $\;x \ge -2$.

Задача на сьогодні

Розв'яжемо $\sqrt{x + 2} = x$, піднісши обидві частини до квадрата:

$x + 2 = x^2$, $\;x^2 - x - 2 = 0$, $\;x_1 = 2$, $\;x_2 = -1$.

Обидва числа входять в ОДЗ. Чи обидва — корені?

$x = 2$: $\;\sqrt{4} = 2$ ✓ — корінь.

$x = -1$: $\;\sqrt{1} = 1 \ne -1$ ✗.

Число $-1$ — сторонній корінь: його додало піднесення до квадрата, а ОДЗ не відсіяла. Які перетворення безпечні — сьогоднішня тема.

Теорія

Рівносильні перетворення і рівняння-наслідки

Означення

Рівняння рівносильні, якщо мають ті самі корені (або обидва не мають коренів).

Друге рівняння — наслідок першого, якщо кожен корінь першого є коренем другого.

Корені наслідку, які не є коренями першого рівняння, — сторонні корені.

Перехід до наслідку не губить коренів, але може додати сторонні. Тому після нього — перевірка підстановкою в початкове рівняння.

Піднесення обох частин до степеня

Непарного — рівносильне перетворення:

$f = g \;\Leftrightarrow\; f^{2k+1} = g^{2k+1}$.

Парного — дає рівняння-наслідок:

$f = g \;\Rightarrow\; f^{2k} = g^{2k}$.

Якщо на ОДЗ $f \ge 0$ і $g \ge 0$, то й піднесення до парного степеня — рівносильне перетворення.

Висновок для $\sqrt{f} = g$

Ліва частина завжди $\ge 0$. Додаємо умову $g \ge 0$ — і піднесення до квадрата стає рівносильним.

Чому це так

Звідки беруться сторонні корені

$x = 2$ і $x^2 = 4$

Рівняння $x = 2$ має один корінь. Піднесемо до квадрата: $x^2 = 4$ — корені $2$ і $-2$.

Причина: $a^2 = b^2 \;\Leftrightarrow\; (a - b)(a + b) = 0$, тобто $a = b$ або $a = -b$.

Отже, $f^2 = g^2$ об'єднує корені двох рівнянь: $f = g$ і $f = -g$.

Для $\sqrt{x + 2} = x$ сторонній корінь $-1$ — корінь «чужого» рівняння $-\sqrt{x + 2} = x$: $\;-\sqrt{1} = -1$.

Чому непарний степінь безпечний

$y = t^3$ (як і $y = t^{2k+1}$) зростає на $\mathbb{R}$: кожного значення набуває один раз, тому $a^3 = b^3 \Leftrightarrow a = b$.

$y = t^2$ зростає лише на $[0; +\infty)$: при $a \ge 0$, $b \ge 0$ маємо $a^2 = b^2 \Leftrightarrow a = b$. Звідси умова $g \ge 0$.

Приклад: непарний корінь

$\sqrt[3]{x^3 - 7} = x - 1$ $\;\Leftrightarrow\;$ $x^3 - 7 = (x - 1)^3$ $\;\Leftrightarrow\;$ $x^2 - x - 2 = 0$.

$x = 2$ або $x = -1$ — обидва корені, перевірка не потрібна: $\sqrt[3]{-8} = -2$.

Дослідження

Сторонній корінь на графіку 🔍

Корені — абсциси точок перетину графіків. Учень каже, скільки коренів бачить; потім підносимо до квадрата й перевіряємо.

Методи

Перевірка чи рівносильна система

Два способи для $\sqrt{f} = g$

1. Наслідок + перевірка. Підносимо до квадрата, розв'язуємо, кожне число підставляємо в початкове рівняння. Зручно, коли корені «гарні».

2. Рівносильна система — перевірка не потрібна:

$\sqrt{f} = g \;\Leftrightarrow\; \begin{cases} f = g^2, \\ g \ge 0. \end{cases}$

Умову $f \ge 0$ не пишемо: вона випливає з $f = g^2$.

Ще два випадки

$\sqrt{f} = \sqrt{g} \;\Leftrightarrow\; \begin{cases} f = g, \\ f \ge 0 \end{cases}$ — умову ставимо на простіший вираз.

$\sqrt[3]{f} = g \;\Leftrightarrow\; f = g^3$ — без жодних умов.

Розв'яжемо $\sqrt{x + 3} = x - 1$: корені ірраціональні, підставляти незручно — тому система.

Приклади

Три типові рівняння

а) $\sqrt{x^2 - 3} = \sqrt{2x}$

$\Leftrightarrow \begin{cases} x^2 - 3 = 2x, \\ 2x \ge 0 \end{cases}$ — умова на простіший вираз.
$x^2 - 2x - 3 = 0$: $\;x = 3$ або $x = -1$.
$x = -1$ не задовольняє $2x \ge 0$. Відповідь: $3$.

б) $x + \sqrt{x} - 6 = 0$

Заміна $t = \sqrt{x}$, $\;t \ge 0$; тоді $x = t^2.$
$t^2 + t - 6 = 0$: $\;t = 2$ або $t = -3$.
$t = -3 \lt 0$ — не підходить. $\sqrt{x} = 2$, відповідь: $4$.

в) $\sqrt{3x + 1} - \sqrt{x + 4} = 1$

Усамітнюємо корінь: $\sqrt{3x + 1} = 1 + \sqrt{x + 4}$ — обидві частини $\ge 0$.
Квадрат: $3x + 1 = x + 5 + 2\sqrt{x + 4}$, тобто $\sqrt{x + 4} = x - 2$.
$\Leftrightarrow \begin{cases} x^2 - 5x = 0, \\ x \ge 2 \end{cases}$ Звідси $x = 0$ — сторонній, лишається $x = 5$.
Перевірка: $\sqrt{16} - \sqrt{9} = 1$ ✓. Відповідь: $5$.
Пастки

Типові помилки ⚠️

ОДЗ — не перевірка

$\sqrt{x + 2} = x$: ОДЗ $x \ge -2$ містить і $2$, і $-1$. Сторонній корінь $-1$ відсіює лише умова $x \ge 0$ або перевірка.

Перевірка не в тому рівнянні

Підставляємо в початкове рівняння. У наслідку $x + 2 = x^2$ «підходять» обидва числа — на те він і наслідок.

Квадрат двочлена

$(x - 1)^2 = x^2 - 2x + 1$, а не $x^2 - 1$.

$\left(1 + \sqrt{x + 4}\right)^2$ $= x + 5 + 2\sqrt{x + 4}$, а не $x + 5$.

Добуток дорівнює нулю

$(x - 2)\sqrt{x - 3} = 0$: $\;x = 2$ — не корінь, бо $\sqrt{-1}$ не існує. Спершу ОДЗ $x \ge 3$; відповідь: $3$.

Практика

Практика у форматі НМТ ✏️

Розв'яжіть рівняння $\sqrt{x + 6} = x$.

А) $-2$
Б) $3$
В) $-2;\ 3$
Г) $2;\ -3$
Д) коренів немає

Розв'язання

$x + 6 = x^2$, $\;x^2 - x - 6 = 0$: $\;x = 3$ або $x = -2$.

Умова $x \ge 0$ (права частина) залишає $x = 3$. Перевірка: $\sqrt{9} = 3$ ✓; $\;\sqrt{4} = 2 \ne -2$ — сторонній.

В — забули умову чи перевірку; Г — помилка в знаках коренів.

Укажіть рівняння або систему, рівносильну рівнянню $\sqrt{5 - x} = x + 1$.

А) $5 - x = (x + 1)^2$
Б) $\begin{cases} 5 - x = (x + 1)^2, \\ x \ge -1 \end{cases}$
В) $\begin{cases} 5 - x = (x + 1)^2, \\ x \le 5 \end{cases}$
Г) $\begin{cases} 5 - x = x^2 + 1, \\ x \ge -1 \end{cases}$
Д) $\begin{cases} 5 - x = (x + 1)^2, \\ x \le -1 \end{cases}$

Розв'язання

$\sqrt{f} = g \Leftrightarrow f = g^2$, $g \ge 0$. Тут $g = x + 1 \ge 0$, тобто $x \ge -1$.

$x^2 + 3x - 4 = 0$: $\;x = 1$ або $x = -4$. Система Б залишає $x = 1$ — це й корінь: $\sqrt{4} = 2$.

А і В мають ще й сторонній корінь $-4$, бо $\sqrt{9} = 3 \ne -3$; ОДЗ $x \le 5$ його не відсіює. Г — $(x + 1)^2 \ne x^2 + 1$.

Розв'яжіть рівняння $\sqrt{x} - 3\sqrt[4]{x} + 2 = 0$.

Якщо рівняння має один корінь, запишіть його у відповідь. Якщо коренів кілька — запишіть їхню суму.

Коротка відповідь: учні записують число, потім показуємо відповідь.

$t^2 - 3t + 2 = 0$: $\;t = 1$ або $t = 2$ — обидва $\ge 0$.

$x = t^4$: $\;x = 1$ або $x = 16$. Сума: $17$.

Розв'яжіть рівняння $\sqrt{x + 2} + \sqrt{3 - x} = 3$.

Якщо рівняння має один корінь, запишіть його у відповідь. Якщо коренів кілька — запишіть їхню суму.

Розв'язання

ОДЗ: $-2 \le x \le 3$. Обидві частини невід'ємні — підносимо до квадрата рівносильно:

$5 + 2\sqrt{(x + 2)(3 - x)} = 9$, $\;\sqrt{(x + 2)(3 - x)} = 2$.

$(x + 2)(3 - x) = 4$, $\;x^2 - x - 2 = 0$: $\;x = 2$ або $x = -1$.

Перевірка: $2 + 1 = 3$ ✓, $\;1 + 2 = 3$ ✓. Сума: $1$. Від'ємне $x = -1$ — не сторонній корінь.

Коротко

Коротко про тему 📌

Запам'ятай! ⭐

Непарний степінь — рівносильно: $\sqrt[3]{f} = g \Leftrightarrow f = g^3$.

Парний степінь — рівняння-наслідок, можливі сторонні корені. Рівносильно:

$\sqrt{f} = g \Leftrightarrow \begin{cases} f = g^2, \\ g \ge 0; \end{cases}$ $\quad \sqrt{f} = \sqrt{g} \Leftrightarrow \begin{cases} f = g, \\ f \ge 0. \end{cases}$

Алгоритм ✍️

1) Усамітнити корінь (два корені — по одному в кожній частині).

2) Піднести до степеня: рівносильна система або наслідок + перевірка в початковому рівнянні.

3) Повторюваний вираз — заміна $t = \sqrt{x}$, $t \ge 0$.

Головна пастка ⚠️

ОДЗ не відсіює сторонніх коренів: у $\sqrt{x + 2} = x$ число $-1$ входить в ОДЗ, але коренем не є.
