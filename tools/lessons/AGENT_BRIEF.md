## Як збирається файл
Пишеш джерело `$SP/lessons/<папка>_<stem>.txt` з маркерами:
```
@@TITLE <точна назва теми без номера>      ← у <title>
@@BRAND <назва курсу з meta.json>           ← у шапці
@@SUBJECT Математика | Алгебра | Геометрія
@@PROFILE A | B                              ← A: на хибну відповідь підказка (quiz-N-hint), на правильну пояснення;
                                               B (для профілів Б і В): після будь-якої відповіді — повне розв'язання
                                               (quiz-N-explanation) і вердикт (<p class="verdict" id="quiz-N-verdict">)
@@CSS      … свій CSS; можна @@INCLUDE plot.css | steps.css | geo.css
@@SLIDES   … <section class="slide-card[ active]" data-slide="N"> …
@@RENDER   … рядки `if (currentSlide === N) renderX();` (віджети малюються при вході на слайд)
@@JS       … свій JS; можна @@INCLUDE plot.js (координатна площина: plane, axesSvg, curveSvg, smooth, broken, num),
              @@INCLUDE steps.js (покрокове розв'язання STEPS + renderEval/evalStep/evalReset, nextStep(id) для .step,
              showTask(n) для перемикача завдань практики; STEPS оголоси ДО @@INCLUDE steps.js),
              @@INCLUDE transversal.js (дві прямі й січна з кутами)
```
Файли в `$SP/parts/` і `$SP/lesson_template.html` — СПІЛЬНІ, НЕ змінюй їх (інші агенти працюють паралельно).
Потрібна інша версія — скопіюй код у свій @@JS.

Команди:
```bash
python3 $SP/assemble.py $SP/lessons/<папка>_<stem>.txt content/school/<папка>/<stem>.html
python3 $SP/check_lesson.py content/school/<папка>/<stem>.html          # має бути «ГОТОВО: усе чисто»
node $SP/shot_lesson.js content/school/<папка>/<stem>.html $SP/shots/<папка>-<stem>   # знімки 1280 світла/темна, 360 телефон;
                                                                       # пише про переповнення й JS-помилки
python3 $SP/sheet.py $SP/shots/<папка>-<stem> wide-light $SP/shots/<папка>-<stem>/sheet.png 0.5  # контактний аркуш → Read
node $SP/interact.js <html> <префікс> "goToSlide(4); revealX()" "…"  # знімок після кожного JS (перевір інтерактив)
```
Запускай із `/home/user/do_kvadratu_pl`. Обов'язково переглянь знімки (Read png): світлу, темну, телефон

## Перевірені на практиці правила (порушення вже траплялись)
- Презентацію показує вчитель: відповіді й висновки — лише після кліку (кнопка «Показати…/Обчислити/Висновок»);
  зміна повзунка знову ховає відповідь. Інструкції — для вчителя («учень називає…, потім перевіряємо»).
- MathJax не рендерить `$…$` у `<text>` SVG — там лише звичайний текст/юнікод (x², √, ∠, °, −).
- НЕ клади формули MathJax усередину `.widget-svg-container` (його CSS робить будь-який svg на 100% ширини —
  формули розлазяться). Текст з формулами — поза цим контейнером.
- У формулах `<` і `>` заборонені — `\lt`, `\gt`. Десятковий дріб: `0{,}75`. Мінус у SVG-тексті — «−».
- Крапку після формули ставимо всередині `$…$`, якщо формула може перенестися окремо.
- У рядках STEPS позначка `[[…]]` охоплює формулу цілком: `'$=$ [[$x^2$]]'`, а не `'$= [[x^2]]$'`.
- Після динамічної зміни HTML з формулами: `MathJax.typesetPromise([елемент])`.
- Довгі формули в стовпчиках `grid-3` вилазять — розбивай на кроки.
- Кожен слайд — одна думка, вміщується на 1280×800 без прокрутки з усіма розкритими відповідями.
- Математика: перерахуй КОЖНЕ число, кожну відповідь, кожен хибний варіант (хибні — типові помилки, правильна рівно одна).
- Термінологія й позначення — як у підручниках НУШ для цього класу; не використовуй ще не вивчених понять.
- Останній слайд — «Коротко про тему» (тег «Коротко»), не входить у ліміт слайдів профілю.

## Рухомі візуалізації (побажання власника)
Де рух допомагає зрозуміти ідею — додавай анімацію: точка біжить по прямій чи графіку, фігура
обертається/зсувається, частини дробу «розрізаються», вектор повертається, переріз «проходить» крізь тіло,
стрибки по числовому променю тощо. Правила:
- анімацію запускає вчитель кнопкою («▶ Показати», «Ще раз»); вона не крутиться безкінечно сама і не
  заважає читати текст; після завершення лишається кінцевий стан;
- реалізація — `requestAnimationFrame` або CSS-переходи/`@keyframes` в SVG; плавно, 0,5–3 с;
- `@media (prefers-reduced-motion: reduce)` — одразу кінцевий стан;
- `shot_lesson.js` знімає слайд одразу — перевір кінцевий стан окремо через `interact.js` (клік і пауза).
