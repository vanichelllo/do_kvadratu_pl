            </div>
            <div class="slide-body grid-2">
                <div class="box definition">
                    <div class="box-title">Означення</div>
                    <p><b>Арифметична прогресія</b> — послідовність, у якій кожен член, починаючи з другого, дорівнює попередньому, до якого додано одне й те саме число $d$ — <b>різницю</b> прогресії:</p>
                    <p class="big-formula">$a_{n+1} = a_n + d$, $\;d = a_2 - a_1$</p>
                    <p>$d \gt 0$ — зростає; $d \lt 0$ — спадає; $d = 0$ — стала.</p>
                </div>
                <div class="box theorem">
                    <div class="box-title">Формула $n$-го члена</div>
                    <p class="big-formula">$a_n = a_1 + (n - 1)d$</p>
                    <p>Від $a_1$ до $a_n$ — $(n - 1)$ кроків по $d$.</p>
                    <p><b>Характеристична властивість:</b> $a_n = \dfrac{a_{n-1} + a_{n+1}}{2}$ — кожен член (крім першого) є середнім арифметичним сусідніх.</p>
                </div>
            </div>
        </section>

            window.renderGauss = function () {
                const n = 8, w = 36, u = 20, x0 = 56, y0 = 200;
                let s = '';
                for (let k = 1; k <= n; k++) {
                    const x = x0 + (k - 1) * w;
                    s += `<rect x="${x}" y="${y0 - k * u}" width="${w - 4}" height="${k * u}" class="bar"/>`;
                    s += `<rect x="${x}" y="${y0 - (n + 1) * u}" width="${w - 4}" height="${(n + 1 - k) * u}" class="bar flip"/>`;
                }
                s += `<text x="200" y="222" class="svg-caption">1 + 2 + … + 8 удвічі = 8 · 9 → сума 36</text>`;
                document.getElementById('gauss-scene').innerHTML = s;
            };

                    s += `<rect x="${x}" y="${top}" width="30" height="${Math.abs(v) * h}" class="bar"/>` + (k < 9 ? '' : `<text x="${x + 15}" y="${v >= 0 ? top - 6 : top + Math.abs(v) * h + 16}" class="svg-caption">a₁₀</text>`);
