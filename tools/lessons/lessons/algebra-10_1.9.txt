            <div class="slide-body grid-2">
                <div>
                    <div class="box definition">
                        <div class="box-title">Означення</div>
                        <p>Функцію $y = f(x)$ називають <b>оборотною</b>, якщо кожного свого значення вона набуває лише в одній точці: з $x_1 \ne x_2$ випливає $f(x_1) \ne f(x_2)$.</p>
                    </div>
                    <div class="box theorem">
                        <div class="box-title">Ознака</div>
                        <p>Якщо функція <b>зростає</b> (або <b>спадає</b>) на області визначення, то вона оборотна.</p>
                        <p>Геометрично: кожна горизонтальна пряма перетинає графік не більше ніж в одній точці.</p>
                    </div>
                </div>
                <div class="box example">
                    <div class="box-title">Приклади</div>
                    <p>$y = 2x + 1$ — зростає ⟹ оборотна.</p>
                    <p>$y = x^2$ на $\mathbb{R}$ — <b>не</b> оборотна: $f(-2) = f(2) = 4$.</p>
                    <p>$y = x^2$ на $[0; +\infty)$ — зростає ⟹ оборотна.</p>
                    <p>$y = \dfrac{1}{x}$ — оборотна, хоч і не монотонна на всій області (спадає на кожному проміжку, значення не повторюються).</p>
                </div>
            </div>

            </div>
            <div class="slide-body grid-2">
                <div class="box definition">
                    <div class="box-title">Означення</div>
                    <p>Нехай $f$ оборотна, $D(f)$ — область визначення, $E(f)$ — множина значень. Функцію $g$, яка кожному $y \in E(f)$ ставить у відповідність те єдине $x \in D(f)$, для якого $f(x) = y$, називають <b>оберненою</b> до $f$.</p>
                    <p class="big-formula">$D(g) = E(f)$, $\;E(g) = D(f)$</p>
                </div>
                <div class="box theorem">
                    <div class="box-title">Властивості</div>
                    <p>1) $g(f(x)) = x$ для $x \in D(f)$, $f(g(y)) = y$ для $y \in E(f)$.</p>
                    <p>2) Графіки $f$ і $g$ (в одній системі координат) <b>симетричні відносно прямої $y = x$</b>.</p>
                    <p>3) Якщо $f$ зростає, то й $g$ зростає (спадає — спадає).</p>
                    <p>$f$ і $g$ — взаємно обернені.</p>
                </div>
            </div>
        </section>

            // Параметрична крива (x(t), y(t))
            function paramSvg(P, fx, fy, a, b, cls) {
                const pts = [];
                for (let i = 0; i <= 200; i++) { const t = a + (b - a) * i / 200, x = fx(t), y = fy(t); if (x >= P.x0 && x <= P.x1 && y >= P.y0 && y <= P.y1) pts.push([x, y]); }
                return pts.length > 1 ? pathPts(P, pts, 'curve ' + cls) : '';
            }
