# ДО КВАДРАТУ — нотатки для Claude

Django-сайт dokvadratu.com.ua (див. README.md). Мова інтерфейсу, контенту й комітів — українська.

## Уроки шкільного курсу: «Зроби урок <тема>»

Власник просить урок назвою або номером теми («Зроби урок 1.3», «5 клас, 2.1»). Урок — це **два файли**,
обидва робимо одразу, якщо не попросили інакше:

| Файл | Що це | Вимоги |
|---|---|---|
| `content/school/<папка>/<номер>.html` | презентація теми («1.3.html») | `docs/html_prompt.md` |
| `content/school/<папка>/bank_<номер>.py` | банк завдань для практики | `docs/bank_prompt.md` |
| `content/school/<папка>/summary-<N>.html` | узагальнення розділу N | там само |

- Повний промпт уроку з методикою за класом і деревом тем — `docs/lesson_prompt.md`. Назви курсу, класу й теми
  беріть дослівно з дерева тем у ньому.
- Зразок готового уроку: `content/school/math-5/1.1.html` і `bank_1.1.py` — тримайтеся їхнього стилю й CSS.
- Папка — один клас одного курсу: `math-5`, `math-6`, `algebra-7`, `geometry-7`, …, `algebra-10`, `geometry-11`.
  У новій папці потрібен `meta.json`: `{"course": "Математика (5-6 класи)", "grade": "5 клас"}`.
- Теми беруться лише з дерева. Якщо потрібної теми (наприклад, з плану учня) у дереві немає — додайте її в кінець
  відповідного розділу в `docs/html_prompt.md` (розділ «7. ДЕРЕВО») і в `materials/management/commands/import_curriculum.py`,
  потім `python docs/build_lesson_prompt.py`. Наявні теми не перейменовуйте: до них прив'язані уроки й завдання.
  Деплой (`import_curriculum` у `build.sh`) додасть нову тему на сайт сам.
- Тему, з якою працюють, видно з наявних файлів: «наступний урок» — це наступна тема за деревом після останньої
  зробленої.

### Перевірка перед комітом

```bash
DEBUG=True python manage.py test materials.tests.SchoolContentTests   # перевірка й імпорт усього content/school
```

Тест проганяє ті самі перевірки, що й сайт (`materials/content_check.py`). Презентацію варто ще й переглянути
в Chromium через Playwright (1280 і 360 px, світла й темна тема). CDN MathJax у контейнері закритий —
візьміть `npm pack mathjax@3.2.2` і підставте `es5/tex-svg.js` через `page.route`.

### Як урок потрапляє на сайт

Коміт → PR → злиття в `main` → деплой на Render. `build.sh` запускає
`import_school_content --all --keep-going`: нові презентації й завдання з'являються на сайті самі.

- Новий урок **одразу публікується** й продається (власник так вирішив). Урок, знятий з публікації в адмінці, деплой
  знову не публікує. Давніші неопубліковані уроки власник публікує сам: фільтр «Готовність уроку → Готові до
  публікації», дія «Опублікувати вибрані».
- Ціни шкільних уроків ставлять «Правила цін шкільних уроків» в адмінці (`materials/pricing.py`): перша тема розділу
  безкоштовна, решта — ціна теми, діагностика — безкоштовна. Ціна, змінена в адмінці вручну, лишається
  (`StudyMaterial.price_is_manual`).
- Деплой перезаписує презентацію, лише коли змінився сам файл (сайт пам'ятає відбиток завантаженого файлу,
  `StudyMaterial.html_source_hash`). Правка уроку в адмінці лишається, доки файл не змінять у репозиторії.
  Тому перед зміною файлу уроку спитайте власника, чи не правив він цей урок в адмінці: якщо правив — нехай
  скаже, що саме, або вставить свою версію, інакше після деплою його правка пропаде.
- Завдання банку додаються без дублікатів (за умовою й варіантами відповіді). Виправлене завдання додасться як нове —
  старе власник видаляє в адмінці («Завдання»).
- Файл із помилками пропускається й не зупиняє деплой; помилки видно в лозі збірки Render.

## Банки завдань НМТ

Завдання для курсу «Підготовка до НМТ / ЗНО» — за промптом `docs/nmt_bank_prompt.md` (лише CHOICE, MATCH, SHORT;
максимально наближені до справжніх завдань НМТ з теми). Файли — `import_files/bank_<NN>*.py`, без `COURSE`/`GRADE`.
