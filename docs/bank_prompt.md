# Промпт: банк завдань для шкільної практики (5–11 класи)

> **Як користуватися.** Скопіюйте все нижче лінії в чат із ШІ і заповніть блок «ЗАВДАННЯ» (назви курсу, класу й теми — дослівно з дерева тем у `docs/html_prompt.md`, розділ 7). Готову відповідь збережіть як `bank_<клас>_<тема>.py` (наприклад, `bank_5_1.1.py`) і завантажте в адмінці: «Завдання → Завантажити завдання». Пробний звіт покаже помилки до імпорту.
>
> Для банків НМТ цей промпт не потрібен — у них немає `COURSE`/`GRADE`, і практика НМТ працює як раніше.

## РОЛЬ

Ти — досвідчений вчитель математики проєкту «ДО КВАДРАТУ». Ти складаєш банк завдань для онлайн-практики після уроку. Сайт щоразу випадково добирає з банку 8–12 завдань, тож банк має бути **великим і різноманітним**, а кожне завдання — **самодостатнім**.

## ЗАВДАННЯ

- **Курс:** {наприклад: Математика (5-6 класи)}
- **Клас:** {наприклад: 5 клас}
- **Тема:** {наприклад: 1.1. Натуральні числа. Ряд натуральних чисел}
- **Побажання (необов'язково):** {акценти, типи задач}

У відповіді — **лише Python-файл** у форматі з розділу 4, без пояснень до і після.

## 1. ЯК ПРАЦЮЄ ПРАКТИКА (від цього залежить, які завдання потрібні)

| Клас | Режим на сайті | Типи завдань | Варіантів у CHOICE |
|---|---|---|---|
| 5–6 | «Тренажер»: 8 завдань по одному; після помилки — **підказка** (`hint`) і друга спроба; потім **розв'язання** | CHOICE, SHORT (**без MATCH**) | 2–4 |
| 7–9 | 10 завдань по одному; після відповіді одразу **розв'язання** | CHOICE, SHORT, MATCH | 4–5 (у 9 класі частина у форматі НМТ: 5 варіантів А–Д) |
| 10–11 | тест із 12 завдань, розбір у кінці | CHOICE, SHORT, MATCH | 5 (формат НМТ А–Д) |

- Сайт сам ставить завдання **від легшого до складнішого** і бере приблизно 20 % завдань з попередніх тем класу на повторення.
- Літери «А)», «Б)»… сайт ставить сам після перемішування варіантів. Писати їх у варіантах **не обов'язково**.
- Учень отримує **три оцінки 1–12 — за критеріями НУШ**. Тому кожне завдання позначене одним критерієм (`skill`), і в банку мають бути завдання всіх трьох критеріїв.

## 2. КРИТЕРІЇ НУШ (`skill`)

| `skill` | Критерій | Що перевіряє завдання | Приклади формулювань |
|---|---|---|---|
| `MODEL` | Моделювання | перекласти ситуацію мовою математики: скласти вираз, рівняння, схему; вибрати потрібну дію; прочитати таблицю чи малюнок | «Який вираз відповідає умові…», «Складіть рівняння…», «Скільки сторінок у книжці, якщо…» |
| `SOLVE` | Розв'язування | виконати обчислення, перетворення, застосувати правило чи алгоритм | «Обчисліть…», «Розв'яжіть рівняння…», «Спростіть…» |
| `ANALYZE` | Аналіз результатів | перевірити, оцінити, порівняти, обґрунтувати, знайти помилку, зрозуміти, чи має відповідь сенс | «Хто з учнів правий?», «Де помилка в розв'язанні?», «Чи може відповідь бути…», «Скільки розв'язків…» |

## 3. СКЛАД БАНКУ

- **Обсяг: 30 завдань** (для 10–11 класів — 36), щоб учень міг пройти практику кілька разів з новими завданнями.
- **Складність (`difficulty`):** приблизно 40 % — `1` (базовий), 35 % — `2` (середній), 25 % — `3` (підвищений).
- **Критерії:** приблизно 30 % `MODEL`, 40 % `SOLVE`, 30 % `ANALYZE`, і кожен критерій має завдання всіх рівнів складності.
- **Типи:** для 5–6 класів — 70 % CHOICE і 30 % SHORT; для 7–11 — 60 % CHOICE, 25 % SHORT, 15 % MATCH.
- **Без повторів:** не роби завдань, що відрізняються лише числами. Змінюй контекст, формулювання і тип міркування.

### Вимоги до змісту за класом

Дотримуйся методичного профілю класу з `docs/html_prompt.md` (розділ 1):

- **5–6 класи:** числа й контексти, близькі дитині; у 5 класі **без від'ємних чисел**. Мова — на «ти», тепла. Підказка (`hint`) — навідне питання чи нагадування правила, **без готової відповіді**.
- **7–9 класи:** терміни — за підручником НУШ цього класу. У розв'язанні — короткі кроки.
- **10–11 класи:** обов'язково ОДЗ і умови застосування; частина завдань — у форматі НМТ.
- **Загальне:** не використовуй понять із пізніших тем.

### Правила для кожного завдання

1. Рівно **одна** правильна відповідь у CHOICE. Хибні варіанти — це **типові помилки** (загублений знак, переплутана дія), а не випадкові числа.
2. **`solution` — обов'язково:** 1–4 короткі кроки, які пояснюють, **чому** відповідь така.
3. **`hint` — обов'язково для 5–6 класів** (для інших — за бажанням): одне речення, яке підводить до ідеї, але не дає відповіді.
4. SHORT: відповідь — ціле число або десятковий дріб (через кому чи крапку; `1/2` теж зарахується). Одиниці виміру пиши в умові («Відповідь запишіть у сантиметрах»), а не в `answer`.
5. Формули — LaTeX у `$...$`. Рядки з формулами записуй як `r"..."`.
6. Малюнок — лише вбудований SVG у `svg_code` (у SVG використовуй `currentColor`), без зображень з інтернету.

## 4. ФОРМАТ ФАЙЛУ

Файл містить **лише присвоєння** `TOPIC_NAME`, `COURSE`, `GRADE`, `TASKS` і літерали Python. Без імпортів, функцій і обчислень.

```python
TOPIC_NAME = "1.1. Натуральні числа. Ряд натуральних чисел"   # дослівно з дерева тем
COURSE = "Математика (5-6 класи)"                               # дослівно з дерева тем
GRADE = "5 клас"

TASKS = [
    {
        "type": "CHOICE",
        "difficulty": 1,
        "skill": "SOLVE",
        "text": r"Яке число наступне за $399$?",
        "options": [
            (r"$398$", False),
            (r"$400$", True),
            (r"$3910$", False),
        ],
        "hint": r"Наступне число на $1$ більше.",
        "solution": r"$399 + 1 = 400$.",
    },
    {
        "type": "SHORT",
        "difficulty": 2,
        "skill": "ANALYZE",
        "text": r"Скільки натуральних чисел стоїть між $5$ і $10$?",
        "answer": "4",
        "hint": r"Випиши їх: $6, 7, \ldots$ Самі числа $5$ і $10$ не рахуй.",
        "solution": r"Між ними числа $6, 7, 8, 9$ — усього $4$.",
    },
    {   # MATCH — лише для 7–11 класів: 3 умови, 4–5 варіантів
        "type": "MATCH",
        "difficulty": 2,
        "skill": "MODEL",
        "text": r"Установіть відповідність між умовою (1–3) та виразом (А–Д).",
        "options": [r"А) $a + 3$", r"Б) $3a$", r"В) $a - 3$", r"Г) $a : 3$", r"Д) $a^3$"],
        "matches": [
            (r"1. число, на 3 більше за $a$", r"А) $a + 3$"),
            (r"2. число, утричі менше від $a$", r"Г) $a : 3$"),
            (r"3. добуток $a$ і 3", r"Б) $3a$"),
        ],
        "solution": r"«На 3 більше» — додавання, «утричі менше» — ділення на 3, «добуток» — множення.",
    },
]
```

**Поля:**

| Поле | Обов'язкове | Значення |
|---|---|---|
| `type` | так | `"CHOICE"`, `"SHORT"` або `"MATCH"` |
| `difficulty` | так | `1`, `2` або `3` |
| `skill` | так | `"MODEL"`, `"SOLVE"` або `"ANALYZE"` |
| `text` | так | умова |
| `options` | CHOICE, MATCH | CHOICE: список пар `(текст, True/False)`; MATCH: список текстів варіантів |
| `matches` | MATCH | пари `(умова, текст правильного варіанта з options — дослівно)` |
| `answer` | SHORT | відповідь рядком |
| `hint` | 5–6 кл. | підказка після першої помилки |
| `solution` | так | розв'язання, яке учень побачить після відповіді |
| `svg_code` | ні | вбудований SVG-малюнок |
| `topic` | ні | назва іншої теми того самого класу, якщо завдання з неї (за замовчуванням — `TOPIC_NAME`) |
